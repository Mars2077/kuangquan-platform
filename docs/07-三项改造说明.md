## 一、图表统一为 ECharts，逐界面修复布局

### 1.1 实现方式

| 项 | 内容 |
| --- | --- |
| 封装组件 | `web/src/components/Chart.jsx`，按需引入 `echarts/core` + Pie/Bar/Line/Gauge/Scatter + Grid/Tooltip/Legend/Title/Graphic + CanvasRenderer |
| 图表构造器 | `donutOption`（环形）、`barOption`（横向渐变条）、`columnOption`（柱）、`lineOption`（面积折线）、`gaugeOption`（仪表盘）、`indicatorOption`（指标进度条） |

| 自适应 | `ResizeObserver` 监听容器尺寸，`setOption(option, true)` 全量替换，卸载时 `dispose()` |
| 产物 | 独立 chunk `charts-*.js` 549.83 kB（gzip 185.46 kB），仅含实际使用的图表类型 |

## 二、高德地图 JS API 接入

### 2.1 配置位置

| 配置项 | 位置 | 说明 |
| --- | --- | --- |
| Web 端 Key | `web/src/components/GeoMap.jsx` 顶部 `export const AMAP_KEY = 'b4c7…f5a9'` | JS API Key，仅在浏览器端使用 |
| 安全密钥 | 同文件 `export const AMAP_SECURITY_CODE = '8001…123c'` | 加载脚本前以 `window._AMapSecurityConfig = { securityJsCode }` 注入 |

> 两者均可用构建期环境变量覆盖，但**不要**写入 `.env.*`（本仓库约定用 `vite --mode` + `define` 注入，见 `web/vite.config.js`）。

### 2.2 加载与降级

1. `loadAMap()` 注入安全配置 → 加载 `https://webapi.amap.com/maps?v=2.0&key=…&plugin=AMap.Scale,AMap.ToolBar`。
2. 12 秒未就绪即 reject，组件 `mode` 由 `loading` 切到 `svg`，自动降级为本地 GeoJSON 矢量底图；下钻、图层控制、图斑属性卡、测量全部保留，仅失去卫星/路网底图。
3. 高德就绪时 `new AMap.Map(el, { mapStyle:'amap://styles/dark', zoom:7, center:[104.0657,30.6595], zooms:[4,17], features:['bg','road','building'] })`。

### 2.3 业务图层映射

| 业务 | 高德对象 | 交互 |
| --- | --- | --- |
| 省/市/县行政区划面 | `AMap.Polygon`（MultiPolygon 逐环展开），填充 `rgba(12,48,88,0.66)`、描边 `rgba(126,214,255,0.62)` | hover 高亮 → click 下钻 `onDrill(adcode)`；`setFitView` 自动适配视野 |
| 区县/地市聚合气泡 | `AMap.Marker` + 自定义 `content`（`.amap-bubble`） | click 下钻；显示「矿山数 + 区县名」 |
| 矿山/矿权点位 | `AMap.CircleMarker`，按状态着色（生产中绿、探矿权黄、地灾红、规划橙） | 点击弹出属性卡，选中放大为白心 7px |
| 选中矿区范围 | `AMap.Polygon` 红色虚线 + 按面积折算的不规则八边形（`minePolygon`） | 随属性卡联动 |
| 工具（测距/测面/坐标定位） | `AMap.Polyline` + 闭合 `Polygon` + 顶点 `CircleMarker` | 地图 `click` 回传经纬度，面积用等距圆柱鞋带公式 |
| 导出 PNG | 优先取 `.geomap-canvas canvas` | 高德瓦片为跨域资源，跨域时报错并提示改用系统截图 |

### 2.4 部署注意事项

1. **域名白名单**：高德控制台 → 应用管理 → 我的应用 → 对应 Key → 设置 → 域名白名单，必须包含正式访问域名（如 `https://<你的域名>`）；IGA Pages 预览域 `*.preview.iga-pages.com` 也需加入，否则脚本返回 `INVALID_USER_DOMAIN`，页面自动降级为矢量底图。
2. **HTTPS**：高德 JS API 仅支持 HTTPS 页面调用；本地 `127.0.0.1` 可直接调试。
3. **配额**：个人开发者 Key 有日调用量限制，演示前请确认配额；超限同样表现为降级。
4. **底图样式**：当前使用官方深色样式 `amap://styles/dark`。该样式对相邻省界使用**红色虚线**，在本项目行政区划面之外可见（西南侧川滇/川藏界一带）；这是高德底图自带样式，不是业务图层，若需隐藏可在控制台创建自定义地图样式（把 boundary 设为透明）后替换 `mapStyle` 的 style id。
5. **CSP**：若站点配置了内容安全策略，需放行 `https://webapi.amap.com`、`https://*.amap.com`（脚本、瓦片、字体）。

## 四、验收路径（建议按此顺序演示）

1. 登录页 → `admin / admin123`（或 `province / 123456` 看省级视角）。
2. 平台分布 `/portal` → 点「数字驾驶舱」。
3. 数字驾驶舱 `/dashboard`：地市气泡下钻到成都市 → 区县气泡 → 点击矿山点位出属性卡 → 右上「图层控制」勾选图层 → 「工具」测距/测面 → 左下「重大任务」打开作战图。
4. 作战图 `/battle`：切年度、搜关键词、导出 CSV。
5. 矿业权管理 `/biz/rights` → 「净矿出让」：筛选、查看详情、点「办理」走流程（提交下一环节 / 退回补正）、导出 Excel、新增记录。
6. 一矿一档 `/archive/1`：二维码、设备、预警、沿革链路。
7. 数据仓 `/warehouse`、移动端 `/mobile`、系统管理 `/system` 各停一屏。
