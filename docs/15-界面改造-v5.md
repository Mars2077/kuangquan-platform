# 界面改造说明（v5 · unslop 重构）

本版在 v4 皮肤基础上做一轮「去装饰、强结构」的改造，依据两件事：

1. 你提出的六条界面问题（列表挡地图、饼图文字歪、详情跳转不合理、地图按钮冗余、掩膜过深、平台分布页冗余 + 顶栏观感）；
2. `unslop` 设计规则（heydamir/unslop，CC-BY-4.0）：一个屏幕只留一个视觉亮点，其余 chrome 保持安静；深度靠表面层级与 1px 发丝边而非阴影；单一强调色；字号与字重收敛；数字统一等宽。

全站仍是深色政务大屏基调、仍只有青色一个强调色，没有引入紫色或新的装饰色。

---

## 1. 中下方列表改为「收起的窄条 + 点击悬浮浮层」

**问题**：列表常驻占据地图下方约 200px，地图被压扁；切换界面时列表还会把页面撑高。

**改动**
- `web/src/pages/Cockpit.jsx`：列表状态由 `useState(true)` 改为 `useState(false)`；网格 `gridTemplateRows` 由 `minmax(0,1fr) auto` 改为单行 `minmax(0,1fr)`，地图可以一直铺到页面底部。
- 收起态是一条 34px 窄条（标题 + 条数 + 「展开列表 ⌄」），点击后以浮层展示完整表格（含筛选、导出、收起）。
- `web/src/styles/pages.css`：新增 `.dash-list`（绝对定位在 `.dash` 底部、`z-index:26`）、`.dash-list-bar`、`.dash-list-float`（`height:min(46vh,420px)`，深色面板 + 发丝边）；小屏改为静态块，浮层高度 `min(52vh,360px)`。

**验证（1920×1080）**：`.dash` 高 1020，地图 1256×1020，收起条高 34；点击后浮层 1920×420、渲染 100 行、`document.scrollWidth = 1920`。

截图：`docs/shots/v5-dashboard.png`（收起）、`docs/shots/v5-dashboard-list.png`（展开）。

## 2. 饼图中心文字居中

**问题**：环形图中间的数字与单位偏右，看着「歪」。

**根因**：`web/src/components/Chart.jsx` 的 `title` 同时用了 `left: 'center'` 与 `textAlign: 'center'`——ECharts 先把标题块居中、再按文字自身宽度做一次居中偏移，等于右移了半个字宽。

**改动**：改用 `graphic` 组合绘制圆心文字（`left: '50%'` / 有图例时 `'34%'`，`top: '50%'`，`textAlign: 'center'` + `textVerticalAlign: 'middle'`），数值与单位分两行、各自垂直居中；同时删掉原来重复定义的第二个 `graphic` 键。

**验证**：`docs/shots/v5-donut.png`（地质勘查卡片，2.63 亿元居中）。

## 3. 面板「详情」按业务含义跳转

**问题**：左右六个面板的「详情」全部跳到矿产地智能管理，等于失效。

**改动**：`web/src/pages/Cockpit.jsx` 新增 `DETAIL_ROUTE`（场景 → 面板 key → 功能页），逐面板指向对应台账：

| 面板 | 跳转 |
| --- | --- |
| 矿产资源储量 | `/biz/deposit/reserve-review` 储量评审备案 |
| 规划与保护 | `/biz/plan/plan-overview` 规划情况概览 |
| 矿业权 | `/biz/rights/rights-stats` 矿业权统计 |
| 地质勘查 | `/biz/geology/geology-explore` 攻深找盲扩能 |
| 绿色矿山 | `/biz/green/green-dynamic` 动态提升 |
| 智慧监管 | `/biz/supervise/supervise-monitor` 动态监测 |

其余场景（矿产地、保护与规划、矿业权、绿色矿山、智慧监管、数智地勘）各自按分区/指标/告警/项目等维度给了独立目标，未命中时回落到该业务域首页。

**验证**：点击「矿产资源储量 › 详情」→ `#/biz/deposit/reserve-review`，标题「储量评审备案」。

## 5. 掩膜变浅 + 按缩放分级展示

**掩膜**：`web/src/components/GeoMap.jsx` 的「全域暗化面」`fillOpacity` 由 `0.52` 降到 `0.22`，卫星影像与省界重新可辨；省界描边保持 1.2px 青色。

**分级展示**：新增 `zoomRef` 与 `zoomTick`，监听 `map.on('zoomend')`；缩放级别 < 8 时只渲染 21 个地市聚合气泡（显示矿山数量），≥ 8 时才铺开 428 个具体矿点。

**验证**（同一页连续缩放）：`zoom 6 → 21 个覆盖物`、`zoom 7 → 21`、`zoom 8 → 449`、`zoom 9 → 449`（428 矿点 + 21 气泡）。

## 6. 去掉平台分布页 + 顶栏重做 + unslop 全站收敛

### 6.1 平台分布页移除
- `web/src/App.jsx`：删除 `/portal` 路由与 `Portal` 懒加载，`/` 与未匹配路径统一重定向到 `/dashboard`。
- `web/src/layout/Shell.jsx`：导航中删除「平台分布」入口。
- `web/src/pages/ModuleHome.jsx`、`web/src/pages/Battle.jsx`：面包屑/返回按钮由「平台分布」改为「数字驾驶舱」。

### 6.2 顶栏重做（单行 60px）
原来是「96px 梯形横幅顶栏 + 40px 独立导航条」两层，带发光胶囊与渐变，正是 unslop 要清掉的 chrome。

- 结构改为单行：品牌（六边形标 + 双行标题）｜7 个场景 + 数据仓 / 移动端 / 系统｜右侧时钟 + 指标监测 + 问题监测 + 用户。
- 视觉改为扁平：`#061526` 实底 + 1px 发丝下边；导航项 30px 行高、`4px` 圆角、悬停浅白 5%、选中青色文字 + 10% 青底；按钮改描边幽灵样式；用户区字号收小（姓名 12px / 单位 10px、头像 28px）并允许省略，避免在 1920 下顶出边界。
- 900px 以下导航收进抽屉（`.hd-nav.is-open`），保留汉堡按钮。
- `web/src/styles/tokens.css`：`--header-h: 96px → 60px`、`--nav-h: 40px → 0`、`--page-pad: 18px → 16px`。
- `web/src/styles/pages.css`：新增「§ v5 unslop 皮肤覆盖」段（最后一层，压过 v4），含 `.app` 网格行修正、`.app-header/.hd-brand/.hd-nav/.hd-right/.hd-btn/.userbox/.avatar` 全套、`.app-nav` 停用、面板/按钮/KPI 去发光、`.page-title` 22px、`.battle-cards > *` 去阴影、小屏气泡只留数字。

### 6.3 修复过程中暴露的真实 bug
导航并入顶栏后 `.app-nav` 被移除，但 `.app` 仍是三行网格（`header / nav / 1fr`），`.app-main` 掉进 0 高度的导航行 —— 表现为**顶栏以下整页空白**。已在 v5 段把 `.app` 改为 `grid-template-rows: var(--header-h) minmax(0, 1fr)`。
