# v12 · 一级/二级导航重做与专题切场动画

> 对应需求：①去掉「指标监测」按钮 ②登录用户姓名改为「马若涵」 ③驾驶舱地图左右加箭头，点击切换专题并带左右栏过渡动画 ④一二级导航重做（参考高星大屏导航结构）⑤时间与日期字号统一。

## 一、顶栏：从「一排链接」改为三段式导航轨

改前：`.app-header` 是一条 flex 横排——品牌、6 个链接、时钟、两个监测按钮、用户信息全部挤在一行，链接之间没有分组，视觉上像一串文字。

改后：三段式 grid（`minmax(0,auto) minmax(0,1fr) minmax(0,auto)`）。

| 区域 | 内容 | 规格 |
|---|---|---|
| 左 | 六边形标记 + 平台名 + 副标题 | 名称 15px/600；副标题 11px `#7fa6cc`；窄屏名称降为「绿矿智用」 |
| 中 | 一级导航轨 | 容器 `#0a1c31` + 1px `rgba(255,255,255,.06)` + 圆角 9 + 内边距 3；item 高 30、圆角 6、13px；hover `rgba(255,255,255,.05)`；选中 `rgba(73,195,255,.16)` + 白字 |
| 右 | 时间 / 问题监测 / 用户 | 时间与日期同字号 13px；用户区头像 28 + 姓名 12 + 单位 10 |

设计依据（GitHub 检索）：`DataV-Team/DataV`、`daidaibg/IofTV-Screen`（477★）、`Alstonsz/BigDataView--` 的大屏导航普遍采用「居中导航条 + 胶囊选中 + 发丝边」结构。本项目只吸收结构，未采纳其渐变/发光装饰——与 unslop 规则（chrome 保持安静）冲突。

已删除：`指标监测` 按钮（原点击跳 `/battle`）。重点任务仍可从一级导航「重点任务」进入。

## 三、地图左右箭头与切场过渡

- 位置：左右各一枚 34×64 胶囊按钮，垂直居中于地图区；`left/right = 栏宽 + 栏间距 + 8px`，随断点取 300 / 320 / 280px 三档，**按钮落在地图内而不是页面边缘**（实测 1920：地图 332–1588，箭头 340–374 与 1546–1580）。
- 交互：点击切到「上一 / 下一」专题（环形），与点击 Tab 走同一个 `switchScene(key)`。
- 过渡：
  1. 左栏 `translateX(-18px)`、右栏 `translateX(+18px)`（反向切场符号相反），260ms `cubic-bezier(.4,0,.2,1)`，同时 `opacity → 0`；
  2. 地图同步 `opacity .4 / scale .996`；
  3. 240ms 后替换专题数据、重置选中要素与测量，再淡入。
- 窄屏：≤1100px（驾驶舱单列堆叠）不渲染箭头，改用 Tab 切换；390 下 6 项导航收进汉堡抽屉（374×232，6 个链接）。

实测 CSSOM（临时禁用 transition 后读取，避免后台标签页冻结过渡）：

| 状态 | `.dash-col--l` | `.dash-col--r` | `.dash-map` |
|---|---|---|---|
| `is-swap-next` | `opacity 0` / `translate(-18px)` | `opacity 0` / `translate(18px)` | — |
| `is-swap-prev` | `opacity 0` / `translate(18px)` | `opacity 0` / `translate(-18px)` | — |
| `is-swap` | — | — | `opacity .4` / `scale(.996)` |

> 说明：headless 采样时标签页处于后台，CSS 过渡不推进、`getComputedStyle` 始终返回旧值 1；为验证规则是否命中，测试时注入 `transition:none!important` 再读取，得到上表。真实前台可见 260ms 过渡。
