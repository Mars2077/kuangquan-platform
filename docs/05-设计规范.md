# 05 · 设计规范

> 设计方法论参考 [taste-skill](https://github.com/Leonxlnx/taste-skill)（anti-slop 前端设计规范，MIT），
> 动效组件来自 [react-bits](https://github.com/DavidHDev/react-bits)（MIT + Commons Clause），动画引擎为 [GSAP](https://gsap.com/)。
> 本文档是**约束**，不是建议：新增界面必须复用下列令牌与类名，不另起一套。

---

## 一、设计系统（一套，不允许第二套）

### 1.1 色彩令牌（`web/src/styles/tokens.css`）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--bg-0` ~ `--bg-4` | `#050f21` → `#16375c` | 页面底色到面板高光，深蓝科技渐变 |
| `--panel` | `rgba(10,32,64,0.58)` | 悬浮面板底 |
| `--line` | `rgba(64,158,255,0.35)` | 1px 描边 |
| `--cyan` / `--cyan-bright` | `#49c3ff` / `#7fe3ff` | 主高亮、数值、地图线 |
| `--blue` | `#2ea8ff` | 主按钮、链接 |
| `--green` | `#35d39a` | 正常 / 推进中 / 在线 |
| `--orange` | `#ff8a3d` | 专题图层、规划类 |
| `--yellow` | `#ffcc44` | 预警 / 延后 / 探矿权 |
| `--red` | `#ff5f57` | 告警 / 已完成旗帜 / 阻断项 |
| `--text-1..4` | `#e8f3ff` → `#6c8aa8` | 四级文字层次 |

**禁止**：紫色 / 薰衣草色系；纯黑 `#000` 大面积；未登记的临时色值（新增颜色须先进 tokens.css）。

语义色助手（`pages.css` 工具类）：`.tone-cyan` `.tone-blue` `.tone-green` `.tone-red` `.tone-yellow` `.tone-orange` `.tone-grey`。

### 1.2 字号与字重

| 档位 | 值 | 用途 |
| --- | --- | --- |
| 巨型数值 | 28px / 700 | 驾驶舱 KPI 数字 |
| 页标题 | 20px / 600 | 页面 h1 |
| 面板标题 | 16px / 600 | Panel 标题 |
| 正文 | 14px / 400 | 表格、表单 |
| 辅助 | 12px / 400 | 说明、单位 |
| 微型 | 11px / 400 | 角标、图例 |

数字统一使用等宽特性（`font-variant-numeric: tabular-nums`），避免跳动。

### 1.3 圆角、间距、阴影

- 圆角三档：`4px`（标签/输入框）、`8px`（卡片）、`14px`（面板/弹窗）。**不允许第四档**。
- 间距 8 的倍数：`4 / 8 / 12 / 16 / 24 / 32`。
- 阴影只用两级：面板 `0 8px 28px rgba(0,20,48,0.45)`；浮层 `0 18px 48px rgba(0,16,40,0.6)`。
- 面板采用斜切角（`clip-path`）+ 左竖条 + 右上「详情」链接，是**全站唯一面板样式**。

### 1.4 组件唯一性

| 组件 | 唯一实现 | 说明 |
| --- | --- | --- |
| 按钮 | `.btn` + `.btn-primary` / `.btn-ghost` / `.btn-danger` / `.btn-sm` | 一种尺寸体系，圆角 4px |
| 卡片 | `.card` / `.door` / `.panel` | 三处场景，视觉同源 |
| 输入 | `.input` / `.select` / `.textarea` / `.input-icon` | 统一 34px 高、深色底 |
| 表格 | `.data-table` | sticky 表头、斑马纹、hover 高亮、选中左描边 |
| 标签 | `.tag` + `.tone-*` | 唯一标签样式 |
| 弹窗 | `components/Modal.jsx` | Esc 关闭、body 锁滚、遮罩模糊 |
| 图标 | `components/Icon.jsx` → `Ic` | 全站唯一图标出口 |

**规则**：不引入第二个 UI 框架；不手写一次性按钮样式；不为单个页面发明新类名前缀。

## 二、动效层（GSAP + react-bits）

### 2.1 原则（来自 taste-skill）

| 允许 | 禁止 |
| --- | --- |
| 按钮 hover 位移 1px、点击下压、卡片抬起 2px | 卡片 tilt / 3D 翻转 |
| 图片或缩略图 hover 放大 1.02–1.03 | 滚动劫持、滚动绑定淡入 |
| 首屏入场动画**只播一次** | 自动轮播、定时自动切换 Tab |
| 数字滚动（CountUp）、文字渐显（BlurText/ShinyText） | 全站无差别动效 |
| 地图范围脉冲（选中图斑） | 持续抖动、闪烁吸引注意 |

必须尊重 `prefers-reduced-motion: reduce`：全局降级到无过渡，动画时长归零（已在 `tokens.css` 统一处理）。

### 2.2 组件使用位置

| react-bits 组件 | 使用位置 | 作用 |
| --- | --- | --- |
| `Threads` | 登录页背景 | 深色流动线条，替代静态渐变 |
| `SpotlightCard` | 登录卡片、门户卡片 | 鼠标跟随聚光（`.door.spotlight-card` 已覆写默认 #111 底） |
| `CountUp` | 登录页四计数、门户三计数 | 数字滚动入场 |
| `BlurText` / `ShinyText` | 登录标题、门户标题 | 一次性渐显/流光 |
| `FadeContent` | 门户区段 | 首屏一次性淡入（非滚动绑定） |
| `StarBorder` | 主按钮描边（重点操作） | 边框流光 |
| `GlareHover` | 缩略图卡 | hover 高光扫过 |
| `AnimatedList` / `Stepper` | 流程节点、动态列表 | 入场逐项出现 |
| `Particles` | 备用背景（当前未启用） | 粒子背景 |

> react-bits 以**源码拷贝**方式进入 `web/src/components/reactbits/`，不是运行时依赖；许可证见项目 README。

### 2.3 GSAP 用法约定

- 仅在 `useEffect` 内创建动画，返回的 `ctx.revert()` 负责清理；禁止全局 selector 批量操作。
- 数字与进度用 tween；时间轴动画统一 `ease: 'power2.out'`、时长 240–600ms。
- 不使用 ScrollTrigger 做「滚动进视口才显示」——内容必须默认可见（可访问性兜底）。

## 三、排版与文案

| 规则 | 示例 |
| --- | --- |
| 标题用名词短语 | 「重点任务作战图」「一矿一档 · 全息数字档案」 |
| 按钮用「动词 + 对象」 | 「导出 Excel」「新增记录」「执行合规预检」 |
| 不使用 slop 词 | 禁止「赋能」「一键智享」「全新升级」等空话 |
| 数字必须带单位 | `2.63 亿元`、`148,029.26 万吨`、`31.8 年` |
| 空值显示 `—` | 不用 `0` 冒充无数据，不编造同比 |
| 演示数据必须标注 | 页脚、README、文档三处注明「模拟数据」 |

## 四、可访问性与性能

- 焦点：全站 `:focus-visible` 统一 2px 青色焦点环，禁止 `outline: none` 裸写法。
- 表单一律 `<label>` 关联；图标按钮必须有 `title` 或 `aria-label`。
- 标题层级：每页仅一个 `h1`，面板用 `h2/h3`，不跳级。
- 对比度：正文 `--text-2` 起步，弱化文字不低于 4.5:1（深蓝底上最小用 `#7fa6cc`）。
- 图片/缩略图必须有替代文本；纯装饰 SVG 用 `aria-hidden`。
- 首屏 JS 分包：`vendor`（React 等）与图表库分离；页面级懒加载（`React.lazy`）。
- 地图 GeoJSON 抽稀（102 要素 / 340 KB），按层级按需加载，不一次性全量请求。

## 五、响应式断点

| 断点 | 行为 |
| --- | --- |
| ≥ 1440px | 标准三栏驾驶舱（296 / 1fr / 296） |
| 1180–1439px | 侧栏收窄，面板内边距压缩 |
| 820–1179px | 驾驶舱右栏折到底部，导航收敛 |
| < 900px | 场景导航转为可折叠抽屉（`.nav-toggle`） |
| < 820px | 单列布局，表格横向滚动 |

## 六、新增页面的检查清单

新增任何页面/组件前，逐条确认：

- [ ] 颜色全部来自 tokens.css，没有新增裸色值
- [ ] 圆角只用 4/8/14 三档
- [ ] 按钮用 `.btn` 体系，没有自造按钮
- [ ] 表格用 `DataTable`，弹窗用 `Modal`
- [ ] 图标来自 `Ic`（@hugeicons），没有 emoji 充当图标
- [ ] hover 有反馈，且尊重 `prefers-reduced-motion`
- [ ] 数字带单位、空值显示 `—`
- [ ] 有一个 `h1`，表单有 label，图标按钮有 `aria-label`
- [ ] 在 1440 / 1180 / 900 三档下不溢出、不重叠
