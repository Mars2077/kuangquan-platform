## 0. 五条不可协商

1. **一页一个 h1、一个筛选区、一个主操作。** `.page-head` 里只有一个 `.page-title`（h1）；筛选项只出现在 `.toolbar`；全页 `.btn-primary` 只有 1 个。
2. **详情 / 编辑 / 流程办理 / 危险确认一律右侧 `.drawer`。** 抽屉内不再叠第二个浮层。
3. **列表页永不整页纵向滚动。** 页头与指标带固定，表格容器内部滚动（sticky 表头），分页吸底。
4. **URL 即状态。** 筛选、分页、标签页、抽屉记录、地图主题全部写进 query string，刷新与分享都能复现（§1.6）。
5. **只用契约类名。** 需要新组件先登记契约 §10，批准前用本文件给出的降级方案（「不补的降级」列）。

### 1.4 返回规则

| 场景 | 规则 | 实现 |
|---|---|---|
| 列表 → 抽屉 | Esc、点 `.drawer-mask`、点关闭 `.icon-btn` 都关闭抽屉；**不改变路由层级**，只删 query `d`/`f` | `navigate(-1)` 仅在抽屉是用 history 打开时；否则 `setSearchParams` 删键 |
| 抽屉 → 二级视图（详情→办理） | 抽屉内切换视图（`.tabs` 或「返回」`.icon-btn`），**不开第二个抽屉** | 局部 state：`view: 'detail' \| 'flow'` |
| 档案页返回 | 回到来源页并**恢复来源页的筛选与页码**；无来源时回 `/biz/deposit/deposit-archive` | `location.state.from` + `sessionStorage` 快照 |
| 作战图返回 | `.breadcrumb` 首项回 `/portal` | `navigate('/portal')` |
| 浏览器后退 | 必须与 UI 返回一致：抽屉打开时后退 = 关抽屉（因为抽屉写进 query） | 所有抽屉用 query 驱动 |
| 未知路由 | `/portal` | `<Navigate to="/portal" replace />` |

### 1.5 URL 状态契约（query keys 统一表）

| key | 含义 | 示例 | 作用页 |
|---|---|---|---|
| `q` | 关键词 | `?q=攀枝花` | T1、T6、T8 |
| `p` | 页码（从 1 起） | `?p=2` | T1、T6、T8 |
| `d` | 抽屉正在看的记录 id | `?d=10231` | T1、T5 内嵌列表 |
| `f` | 抽屉视图：`new` \| `edit` \| `flow` \| `del` | `?d=10231&f=flow` | T1 |
| `tab` | 标签页 | `?tab=users` | T6、T8 |
| `layer` | 地图主题 | `?layer=green` | T2 |
| `rg` `mn` `st` `yr` | 区域 / 矿种 / 状态 / 年度筛选，键名与 `spec.filters[].key` 一致 | `?rg=510100&st=在办` | T1、T2 |

| 角色 | 可见导航 | 主操作 | 数据范围 |
|---|---|---|---|
| `admin` | 全部 11 项 | 全部 | 全省 |
| `province` | 10 项（无「系统」） | 全部 | 全省 |

## 2. 页面模板

八套线框 + 三套变体（业务域落地、登录、抽屉）。每套给出：结构图（含像素/比例）、区块表、状态位、实现要点。
所有页面的 `main` 是 `.app-main`（唯一纵向滚动兜底），但**列表页内部不再整页滚动**——高度用下面的公式锁死。

### 2.0 三层结构的通用尺寸

```
.app-header  64                                    ← 固定
.app-nav     44                                    ← 固定
.app-main    calc(100vh - 108)  overflow-y:auto    ← 兜底滚动
  .app-page  padding 20，max-width 1920 居中
    .page-head      64（标题 28 + 描述 13 + 操作右对齐）      8%
    .kpi-row        88（4 × .kpi-card 等高，gap 16）         11%
    .content        calc(100vh - 108 - 40 - 64 - 88 - 32)    81%
```

- 页头到指标带 gap `--sp-4`（16），指标带到内容 gap `--sp-4`；内容内部 `.toolbar` 48 + gap 12 + 主体。
- 表格可视高 `calc(100vh - 444px)`，最小 320：`64+44+40(页边距)+64(页头)+88(指标带)+16*2(间距)+48(工具栏)+12+36(分页)` → 用 CSS 变量 `--table-h` 落一次，各页复用。
- 页面宽度 ≥1920 时 `.app-page` 居中留白，不拉伸卡片。
- 断点只保留四档：`≤900`（单列、抽屉全屏）、`901–1200`、`1201–1600`、`>1600`。旧 40 条 media 全部作废（§5 C-07）。

- 4 个 KPI 中第一个固定为「当前筛选 N 条」（随筛选变化），其余 3 个取 `stats.sums` 前三项，口径写在 `.kpi-label`（例：`在办（含退回补正）`）。

**抽屉硬规则**

1. 抽屉只有一个，**内部不叠第二个 `.drawer` / `.popover` / 浏览器 confirm**；需要二级信息用视图切换或 `.tabs`。
2. 详情→流程：同一抽屉内 `view` 切换，标题从「净矿出让 · 川自然资矿出〔2024〕12 号」变「流程办理 · 储量评审」，左侧加返回 `.icon-btn`。
3. 打开时焦点进 `.drawer`，Tab 循环，Esc 关闭；关闭后焦点回到触发行。
4. 有未保存修改时关闭 → 在抽屉内弹一条内联确认条（不是第二个弹窗）：`.drawer-foot` 上方 `.alert-line`？→ 用 `.list-item` 行 + 两个按钮，见 §5 C-01。
5. 内容高度 < 200 时 `.drawer` 顶部对齐，不垂直居中。

**何时抽屉、何时全屏浮层、何时新页面**

| 判据 | 抽屉 520 | `.drawer--lg` 720〔U-05〕 | `.drawer--full`〔U-05〕 | 新页面 |

| 是否需要对照列表 | 是（列表仍可见） | 是 | 否 | 否 |
| 典型场景 | 详情、编辑、流程、删除确认、筛选 | 字段 12–24 的表单、档案内嵌表全屏 | 地图选点、打印预览、导入校验结果 | 驾驶舱、作战图、档案、数据仓、移动端、系统 |
| 是否进 URL | `?d=` | `?d=` | `?d=` | 路由 |

**结论：全站没有「弹窗 Modal」。** 旧版 5 个 Modal（新增/编辑、详情、流程、删除、问题监测）全部改写为抽屉或页面。

## 3. 交互状态

### 3.1 状态矩阵

| 状态 | 页面级（首屏） | 区块级（卡片/表格/图表） | 类名 | 恢复动作 |
|---|---|---|---|---|
| 加载 | `.skeleton` 3 行 + 表格 5 行骨架 | 按钮 `is-loading`〔U-10〕；卡片内 2 行 `.skeleton-line` | `.skeleton .skeleton-line` | 自动 |
| 空·无数据 | 整页 `.empty` + 主操作 | 表格 `.empty` + 「新增记录」 | `.empty .empty-icon .empty-text` | 新增 |
| 空·筛选无结果 | — | 表格 `.empty` + 「重置筛选」 | 同上 | 清筛选 |
| 空·未选择 | 抽屉/档案未带 id | 「请从列表选择一条记录」 | 同上 | 返回列表 |
| 空·无权限 | 整页「当前账号无权查看<对象>」 | — | `.empty` + `.btn-ghost` | 申请权限（外链或说明） |
| 错误·网络 | 整页 `.empty` 变体 + 「重试」 | 卡片内 `.empty` 变体 + 「重试」 | `.empty.is-error`〔U-07〕 | 重试 |
| 错误·接口 | 同上 + 小字错误码 | 同上 | 同上 | 重试 / 联系管理员 |
| 错误·404 | 「未找到该<对象>」+ 两个按钮 | — | `.empty` + `.page-head` | 返回上一级 |
| 错误·导出/上传 | — | `.toast--err` 或卡片内错误行 | `.toast--err` | 重新执行 |
| 进行中·长任务 | — | 按钮 `is-loading` + 进度文字 | 〔U-10〕 | 可取消（>10s） |
| 成功 | — | `.toast--ok` 3s | `.toast--ok` | 自动消失 |
| 危险 | — | `.drawer` 确认变体 | `.btn-danger` | 取消 / 确认 |

**加载时序规则**

- 请求 < 300ms 不显示骨架（避免闪烁）；≥300ms 显示；≥10s 追加「仍在加载，可稍后刷新」一行 `.page-desc`；≥30s 转为错误态（可重试）。
- 局部刷新（刷新按钮、筛选切换）**不清空表格**：表格保持旧数据 + 顶部 2px 进度条（用 `is-loading` 的伪元素，不加类），避免整块骨架抖动。
- 骨架尺寸必须与真实内容一致（KPI 4 格 → 4 个骨架卡；表格 5 行 × 40px），否则会跳版。

### 3.2 空态四种，文案与动作必须成对

| 场景 | 标题（`.empty-text`） | 动作 | 禁止 |
|---|---|---|---|
| 库为空 | 暂无矿产地数据 | `.btn-primary` 新增矿产地 | 只写「暂无数据」不给下一步 |
| 筛选无结果 | 没有符合筛选条件的矿业权 | `.btn-ghost` 重置筛选 | 提示「换个条件试试」这类空话 |
| 未选择 | 请从左侧列表选择一条记录 | 无（返回由 Esc 承担） | 显示空白表格 |
| 无权限 | 当前账号无权查看储量评审备案 | `.btn-ghost` 申请权限说明 | 显示假数据或「加载失败」 |

### 3.3 错误态

- 卡片内错误：`.empty.is-error`〔U-07〕= 图标（警示色 `--orange`）+ 一句「<对象>加载失败，请重试」+ 小字错误码 `ERR_500` + 「重试」`.btn-ghost`。
- 页面级错误：同样形态，放在 `.content` 区域，保留 `.page-head` 与 `.kpi-row`（不要整屏白屏）。
- **不弹全局 alert、不弹 Modal、不 toast 报错到角落了事**（错误必须留在发生位置可重试）。
- 档案 404 用「未找到该矿山档案」+「返回上一页」「进入矿产地一本账」两个出口。
- 导出/上传失败用 `.toast--err`（一次性动作，无位置可留）。

### 3.4 无权限

- 导航项隐藏（不置灰、不加锁图标）。
- 主操作按钮不渲染；只读视图保留页头、指标带、表格与详情抽屉。
- 抽屉打开时若中途失权：`.drawer-foot` 按钮消失，`.drawer-body` 顶部插一行 `.tag--grey`「只读」。
- 字段级：整行不渲染；敏感字段脱敏（§1.6）并在 `.kpi-label` 或 `.field-label` 后加 `.tag--grey`「脱敏」。

### 3.5 危险操作确认

危险清单（一律 `.btn-danger` + 二次确认抽屉）：删除记录、停用账号、退回补正、出库、作废、覆盖入库、批量导出全量。

```
标题   确认删除？
正文   净矿出让 · 川自然资矿出〔2024〕12 号
       删除后该记录与关联流程节点不可恢复。
       影响：1 条台账记录、2 条流程节点。
底部   [取消]            [确认删除]  ← .btn-danger
```

- 标题句式「确认<动作>？」，正文含**对象名 + 后果 + 影响面**，主按钮带对象动作（「确认删除」「确认停用」），不写「确定」。
- 不需要输入文本二次校验（本系统无破坏性到需要打字的场景）；不跳页面、不开第二层。
- 成功后关抽屉 + `.toast--ok`「已删除 1 条记录」+ 列表原地刷新。

### 3.6 成功与长任务

- 成功：`.toast--ok`，文案「已<动作>」+ 数量（`已导出 128 条`、`已入库 1 个文件，1,204 条`），3s 自动消失，右下堆叠，最多 3 条。
- 长任务：上传显示文件名 + 进度百分比（卡片内一行 `.list-item`）；导出 > 2s 时按钮文字变「导出中…」并 `is-loading`；> 30s 允许离开页面，完成时 `.toast--ok`。

### 3.7 键盘、焦点与触控

| 项 | 规则 |
|---|---|
| Esc | 关闭最上层抽屉；有未保存修改时先显示内联确认条（不关闭） |
| Tab | 抽屉内焦点陷阱；`.drawer-mask` 外的元素 `aria-hidden` |
| Enter | 表单内提交（`.textarea` 内换行）；表格行聚焦后 Enter 打开详情（行加 `tabIndex=0`、`role="button"`） |
| 关闭后 | 焦点回到触发行或触发按钮 |
| `/` | 聚焦当前页 `.toolbar-search`（列表页） |
| 触控 | 所有可点目标 ≥32×32；文本按钮 ≥32 高（`.btn-sm` 保证）；表格行高 ≥40（`.is-dense` 36）；手机壳内 `.m-item` ≥44 |
| 对比 | 正文 ≥ `--text-2`；`.tag` 文字与底色对比 ≥4.5:1；`.flag` 同 |
| 动效 | 抽屉 180ms `transform`；toast 150ms 淡入；`prefers-reduced-motion` 下位移与淡入全部关闭 |

## 4. 文案规则

### 4.1 标题

- 名词短语，不加标点，不以动词开头：`净矿出让台账`、`矿产地概况`、`重点任务作战图`、`绿矿智用数据仓`。
- 页面 h1 = 「对象 + 页型」：台账页 `…台账`、概览页 `…概况`、统计页 `…统计`、工具页 `…工具`、管理页 `系统管理`。
- `.card-title` ≤10 字，`.panel-title` ≤8 字；同一屏内标题不重复（两个「统计分析」必须改成「权类结构统计」「区域分布统计」）。
- 标题里不出现财年、区划名以外的修饰（`2026 年` 只在作战图 h1 里出现）。

### 4.2 按钮：动词 + 对象

| ✅ 正确 | ❌ 错误 | 原因 |
|---|---|---|
| 新增记录 | 新增 / 添加 | 缺对象 |
| 导出 Excel | 导出 / 下载 | 缺格式 |
| 提交储量评审 | 提交 / 确定 | 缺对象 |
| 退回补正 | 退回 | 缺后果 |
| 重置筛选 | 重置 / 清空 | 缺对象 |
| 查看档案 | 查看 / 详情 | 「详情」是位置不是动作 |
| 确认删除 | 确定 / 是 | 危险操作必须点名动作 |
| 登录系统 | 登录 / 进入 | 可接受，统一取「登录系统」 |
| 保存修改 | 保存 | 缺对象（仅表单抽屉使用） |

- 全页只有一个 `.btn-primary`，其余 `.btn-ghost` / `.btn-text`；表内操作 `.btn-text`。
- 同一个动作全站同名：删除 / 停用 / 退回补正 / 导出 Excel / 上传并入库。
- 不允许在按钮里写省略号或图标代替文字（`.icon-btn` 必须有 `aria-label`，tooltip 用 `title`）。

### 4.3 空态与错误文案模板

```
空态：  暂无<对象>数据
        没有符合筛选条件的<对象>
        请从列表选择一条<对象>
无权限： 当前账号无权查看<对象>
错误：  <对象>加载失败，请重试（<错误码>）
        网络连接失败，请检查网络后重试
        未找到该<对象>
成功：  已<动作> <数量><单位>
确认：  确认<动作>？<对象名> <后果说明>
```

- 「<对象>」必须具体：矿产地、矿业权、规划区块、绿色矿山申报、预警、工单、设备、账号、文件。不写「数据」「信息」「内容」。
- 空态文案 ≤20 字，错误文案 ≤24 字 + 错误码；不写两句以上解释。

### 4.4 数字、单位、日期

| 项 | 规则 | 例 |
|---|---|---|
| 千分位 | 整数部分每 3 位逗号 | `148,029.26` |
| 单位 | 紧跟数值，不换行，`.kpi-unit` 承载 | `2.63 亿元`、`148,029.26 万吨`、`31.8 年` |
| 百分比 | 1 位小数 | `86.7%` |
| 同比 | 带符号，涨绿跌红（本系统语义色：增 = `--green`，降 = `--red`，仅在指标带） | `+12.4%` / `-3.1%` |
| 空值 | `—`（em dash），不用 0、不用 `--`、不用「暂无」 | `—` |
| 0 与空 | 真实的 0 显示 `0`，缺数据才显示 `—` | |
| 日期 | `YYYY-MM-DD` | `2026-11-18` |
| 日期时间 | `YYYY-MM-DD HH:mm` | `2026-11-18 09:30` |
| 相对时间 | 只用于 toast 与 `.list-meta` 的「刚刚」 | 表格内一律绝对时间 |

### 4.5 状态词表（与数据字典对齐，不新造）

| 域 | 词表 |
|---|---|
| 流程 | 待提交 / 在办 / 已办结 / 已退回 |
| 矿业权 | 有效 / 临期（≤90 天）/ 过期 / 注销 |
| 绿色矿山 | 国家级 / 省级 / 市级 / 未入库 |
| 预警 | 一级（红）/ 二级（橙）/ 三级（黄）/ 已消除 |
| 工单 | 待分派 / 处置中 / 待核实 / 已办结 |
| 设备 | 在线 / 离线 / 故障 |
| 账号 | 启用 / 停用 |

- 颜色与词绑定：`.tag--green` 恒为正向（有效/已办结/在线），`.tag--red` 恒为负向（过期/一级预警/故障），`.tag--yellow` 为临期/待办，`.tag--grey` 为停用/未开始。

### 4.6 禁词与空话

| 禁用 | 原因 | 改写 |
|---|---|---|
| 整体良好 / 总体平稳 / 有序推进 / 态势向好 | 无数字支撑的判断 | 给出 1 个数字或删除 |
| 赋能 / 一键智享 / 全新升级 / 智慧化提升 | 营销词 | 删除或写具体动作 |
| 明显改善 / 大幅提升 / 有效增强 | 不可验证 | `较上年 +12.4%` |
| 数据加载中，请耐心等待 | 空话 | 「加载中」（骨架已表达） |
| 暂未开放 / 敬请期待 | 悬空 | 隐藏入口，或写「需 <角色> 权限」 |
| 其他 /  miscellaneous | 兜底状态 | 归入具体分类或 `—` |
| 哦 / 啦 / 呢 / ～ / ！ | 语气词 | 删除 |

### 4.7 演示数据标注

每个含模拟数据的页面右上角或 `.page-desc` 末尾标注 `.tag--grey`「模拟数据」；全站同一页只标一次。数据来源说明放 `.page-desc`（例：`数据来源：矿产资源储量数据库，按月同步`），不放在标题里。

### 6.4 质检自检清单

1. `node scripts/check-classes.mjs` 退出码 0（无 `UNKNOWN_CLASS`）。
2. 台账类页面（`/biz/*`）在 1440×900 下**整页不出现纵向滚动条**（`.app-main` 的 `scrollHeight == clientHeight`），表格容器内部可滚；档案与数据仓允许整页滚动，但其内部卡片不再套第二层滚动。
3. 每页恰好 1 个 `h1`（`.page-title`），标题层级 h1→h2（`.card-title`/`.panel-title`）→h3。
4. 每页 `.btn-primary` 数量 = 1（只读页为 0）。
5. 所有详情/编辑/流程/删除确认都能用 Esc 关闭，且焦点回到触发行。
6. 所有表格在 390×844 下可横向滚动，`min-width ≥ 640`（作战图 720）。
7. 所有可点目标 ≥32×32（文本按钮 ≥32 高），`.tag` 不可点。
8. 全站无 `window.confirm` / `alert` / `confirm(` 字面量。
9. 空态/错误态各命中至少 1 次人工触发，文案符合 §4.3 模板。
10. 刷新任一页（含 `?d=` / `?tab=` / `?p=` / `?layer=`）状态可复现；浏览器后退能关抽屉。
