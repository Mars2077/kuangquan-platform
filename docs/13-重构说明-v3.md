# v3 界面重构说明

> 触发：用户反馈「目前系统不合理的重构一遍，整体状态很糟糕，工程量打也不要紧，要求系统交互简洁，设计合理，内容分布合理，UI 美观大气」。
> 原则：**不重写业务、只重做界面层**。40 个功能点、7 个驾驶舱场景、数据接口与业务规则全部保持不变。

---

## 1. 为什么之前修不完

| 事实 | 数据 |
| --- | --- |
| v2 样式总行数 | 4 份 CSS 共 **4494 行 / 113 KB** |
| 针对单一 bug 的追加补丁 | `pages.css` 内 **R-01 … R-31 共 30 条** |
| 媒体查询 | **43 个**（其中 pages.css 40 个） |
| 同一类名被覆盖 | `.panel-body` 的 `justify-content` 需要 **特异度 0,4,0** 才能压过另一条规则 |

结论：不是某个页面没调好，而是**缺少统一的版式契约**——每来一个反馈就加一条补丁，补丁之间互相打架。

---

## 2. 做法：先冻结契约，再按契约重建

1. **诊断与基线**：`git tag v2.2-stable`，旧 CSS 移入 `web/src/styles/_legacy/`（重构完成后已删除）。
2. **冻结组件契约**：新增 `docs/11-组件契约-v3.md`，把类名、令牌、页面模板、原子组件、状态约定一次性定死，作为唯一事实来源；任何新类名必须先登记再落地。
3. **交互规范先行**：`docs/10-交互规范-v3.md`（878 行）定义站点地图（L0–L4）、三层页面结构（页头 64 / 指标带 88 / 主内容）、11 个页面模板、URL query 契约、状态矩阵、文案规则。
4. **设计系统重建**：四层 CSS 从零重写，**3627 行、8 个媒体查询、0 个 `!important`**；配 `/ui-kit` 对照页与 `scripts/check-classes.mjs`（全仓 266 个类、1892 处引用，未知类名 0）。
5. **页面按模板重写**：门户、驾驶舱、作战图、业务域首页、通用功能页、专题面板、一矿一档、数据仓、移动端、系统管理，逐页套模板。
6. **全量复测**：12 条路由 × 4 档视口（1920×1080 / 1440×900 / 1280×800 / 390×844）共 48 条记录，见 `docs/12-v3-评审.md`。

## 5. 交互简化的具体措施

1. **入口收敛**：顶栏只留「指标监测 / 问题监测」两个胶囊 + 用户菜单；导航一行 11 项（平台分布 + 7 场景 + 数据仓/移动端/系统），不再有重复入口。
2. **抽屉统一**：新增/编辑/详情/办理/删除确认全部走 `Drawer.jsx`，Esc 可关、焦点被限制在抽屉内。
3. **状态统一**：状态用 `.tag--*` 六色；按钮四变体 + 小号 `.btn-sm`；触控目标 ≥ 24px。
4. **空态 / 骨架 / 错误**：统一 `.empty`、`.skeleton`、`.empty.is-error`，不再出现「加载中一片空白」。
5. **可访问**：每页 1 个 `h1`（驾驶舱用 `.sr-only`）、图表 `role="img"`、表单 label 齐全、`:focus-visible` 焦点环。

## 7. 已知限制

1. **高德底图国界**：`amap://styles/dark` 自带相邻省界红色虚线（西南侧），JS API 无关闭接口；如需去掉须在高德控制台自定义地图样式。
2. **演示数据**：全部为按真实业务口径生成的演示数据（`server/src/seed.js`），非真实台账。
3. **静态部署版**：写操作落在浏览器 `localStorage`（键 `kq_demo_journal_v1`），文件上传仅记录元数据，详见 README「方式三」。
