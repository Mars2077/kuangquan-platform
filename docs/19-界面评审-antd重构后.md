## 1. 总评

**结论：这一轮把「能不能用」修好了，还没把「好不好看、顺不顺手」修好。**

上一轮的三个 P0（全站不可滚动、≤1360px 驾驶舱面板塌成 2px、宽表格被裁且不能横向滚动）在 1920 下已全部消失：5 条内容型路由都能正常整页滚动，表格与容器同宽不再溢出，390 下页面无横向滚动（`scrollX=0`、`docW=390`）。抽屉宽度 520px 与契约一致，KPI → 表格 → 分页的纵向顺序也回到规范。

## 2. 全站共性问题

### G-01 字号档位失控（P1）

实测出现 **9、10、10.5、11、11.5、12、12.5、13、14、15、16、22、26、28** 共 14 个字号，其中 3 个是浮点值（10.5、11.5、12.5），10px 及以下文本数量惊人：

| 界面 | ≤10px 文本数 | ≤11px 文本数 |
| --- | --- | --- |
| `/hub` | 66（10px）+ 40（10.5px） | 161 |
| `/warehouse` | 56（字段 tag） | — |
| `/mobile` | 57 | 69 |
| `/system` | tag 20 个 | — |
| `/dashboard`（390） | 12（9px）+ 24（10px） | 41 |
| `/archive/1` | 10 | 29 |

10px 的「分组小标题」「字段 tag」「序号 01」在 1920 桌面上肉眼可辨但明显偏小，在 390 上等同于不可读。字号没有阶梯规则，是「每处按需微调」留下的痕迹。

**建议**：按契约只保留 `--fs-11/12/13/14/16/20/28` 七档；10px、10.5px、11.5px、12.5px 全部就近归并（≤10.5 → 11，11.5/12.5 → 12）；分组小标题 ≥12px，表格辅助文本 ≥11px。

### G-02 颜色越界（P1）

`/dashboard` 单页出现 13 种文本色，其中 4 档**不在 token 内**：`rgb(207,228,255)`（148 处，最常用正文色）、`rgb(157,179,204)`（16）、`rgb(232,244,255)`（40）、`rgb(223,240,255)`；另有 5 处品牌外色：

| 色值 | 出现位置 | 问题 |
| --- | --- | --- |
| `#33bcb7`（青绿，23 处） | `/hub` | 与 `--cyan #49c3ff` 抢强调色 |
| `#3c89e8` / `#6abe39` | `/system` 角色、状态 tag | 非 token 的蓝/绿，且底色 `rgb(17,26,44)` / `rgb(22,35,18)` 也是新色 |
| `#2a92dc` / `#d54c4d` | 功能页「新增」「编辑/删除」 | 主按钮出现第二种蓝，与 `#49c3ff` 冲突 |
| `#8ff0c8`（薄荷绿） | `/archive/1` | 与 `--green #35d39a` 并存 |
| `#3c89e8`（60,137,232，13 处） | `/mobile` | 同上 |

**建议**：文本色收敛到 `--text-1..4` 四档（正文用 `--text-2`，次要 `--text-3`，禁用/单位 `--text-4`）；语义色只用 `--green/--orange/--yellow/--red`；主按钮统一 `--cyan`；`#33bcb7`、`#3c89e8`、`#6abe39`、`#8ff0c8` 全部替换。

### G-03 圆角混用（P2）

`/dashboard` 圆角分布：`0px×286、8px×27、2px×14、4px×11、6px×8、50%、999px`；`/hub`：`4px×85、6px×39、8px×11`；`/warehouse`：`4px×60、6px×16、8px×6、24px×1`。契约只允许 8/12/16，实际以 antd 默认 4/6 为主，另有 Segmented 的 2px、手机壳的 24px。

**建议**：antd 主题 `borderRadius: 8`，`borderRadiusSM: 8`，`borderRadiusLG: 12`；手机壳例外单列并在契约登记；2px/4px/6px 一律并入 8px。

### G-04 二级文字对比度不足（P2）

WCAG 2.1 相对亮度计算：

| 前景 | 背景 | 对比度 | 判定 |
| --- | --- | --- | --- |
| `--text-4 #5d7d99` | `--bg-1 #071729` | **4.18:1** | 正文 12px 不达 4.5:1 |
| `--text-4 #5d7d99` | `--panel #0b2138` | **3.77:1** | 不达 4.5:1 |
| `--text-3 #8fb0cc` | `--bg-1 #071729` | 7.95:1 | 通过 |
| `--text-2 #c2dbf2` | `--bg-1 #071729` | 12.64:1 | 通过 |

而 10–12px 的辅助文字（单位、说明、日期）大量使用 `--text-4`。

**建议**：`--text-4` 只用于 ≥16px 或纯装饰；正文辅助文字改用 `--text-3`；如必须保留 `--text-4`，把它提亮到 `#6f91ae`（4.6:1）。

### G-05 触控目标普遍低于 24px（P1）

| 元素 | 实测 | 位置 |
| --- | --- | --- |
| 「详情」钻取链接 | **47×17** | `/dashboard` 390 |
| antd Switch | **26×15** | `/system` 用户表 ×28 |
| 表格行内「详情/编辑/删除」 | **42×26** | 功能页 |
| 抽屉关闭按钮 | **22×22** | `/system` 新增用户 |
| 工具栏「重置/导出/新增」 | 46–64×26 | 功能页 |
| 「返回 / 刷新 / 矿产一本地账」 | 63–94×26 | `/archive/1` |

**建议**：所有可点击元素命中区 ≥ 32×32（视觉可以 26px，用伪元素扩大热区）；表格行操作改为「⋯」更多菜单或 32×32 图标按钮；Switch 用 `size="default"` 而非 `small`。

### G-06 顶栏与导航存在同页异名入口（P2）

- 顶栏「指标监测」→ `/battle`，导航第一项「重点任务」→ 同一页 `/battle`：**一个页面两个名字、两个入口**。
- 顶栏「问题监测」（弹层）与门户页「指标监测」按钮、作战图页并存，语义边界不清。
- 用户菜单与导航右侧「数据仓 / 移动端 / 系统」三个入口重复。

**建议**：保留导航「重点任务」作为唯一入口，顶栏两个 pill 合并为「监测预警」一个入口（内含指标/问题两个 Tab）；用户菜单只留账号相关（个人中心、退出），不再承载模块跳转。

## 5. 最值得先做的 5 条

1. **收字号、收颜色（G-01/G-02）**：把 14 档字号并到 7 档、把 8 种非 token 色全部替换。这一条不动布局，却能一次性消掉「补丁感」和大部分「AI 味」，风险最低、收益最大。
2. **功能页去掉状态三入口与重复 KPI（F-01）**：状态只留一个 select，KPI 换成「新增/办理时长/退回率/超期」；顺手把分页改 sticky（F-02）。这直接回应用户说的「重复筛选、同页多个入口」。
3. **`/hub` 二选一（H-01/H-04）**：删掉全量 40 行表或删掉模块卡片网格；页面从「两个导航 + 两个滚动」变成一条主线。
4. **驾驶舱底部列表补齐容器（D-02/D-05）**：浮层加面板底 + 阴影，toggle 常驻，补 ESC/遮罩关闭，列宽 fixed 全左对齐——这是用户点名诉求①的收尾。
5. **修 `/system` 抽屉区划预填（S-02）**：新区划置空必填、按角色联动，避免误建带错区划的账号；同时把 KPI 换成真正的运行指标（S-01）。
