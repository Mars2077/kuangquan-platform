# v10 掩膜回归 + 下钻改为「原地缩放」

> 修正 v9 中被移除过头的行政区划掩膜，并把「点击辖区」由地图重建改成原地缩放。
> 涉及 1 个组件文件（`web/src/components/GeoMap.jsx`），未改接口、数据与业务规则。

## 1. 行政区划内的掩膜恢复（v9 的 0.001 太淡）

v9 为了「去掉深色掩膜」把行政区划面填充压到 `fillOpacity 0.001`，等于连辖区内部的层次也没了。本轮恢复为三档：

| 状态 | 填充色 | 不透明度 | 说明 |
|---|---|---|---|
| 常态 | `#061a34` | **0.22** | 辖区内部轻微压暗，卫星影像的纹理与山形仍可辨认 |
| 悬停 | `#0a2b4d` | **0.42** | 指针移入时加深一档，并提升描边不透明度到 0.95，明确「可点」 |
| 选中（当前辖区） | `#0d3f70` | **0.34** | 比常态深、比悬停浅 |

- 省界描边保持青色 1.2px（选中 2px）。
- 覆盖邻省的「全域暗化面」**仍然不生成**——掩膜只作用在行政区划多边形内部，这正是本轮要求「行政区划内的掩膜不要去掉」与 v9「去掉整块暗化面」的区分点。
- 矢量降级模式（SVG）同步调整：常态 `rgba(46,168,255,0.14)`、选中 `rgba(73,195,255,0.28)`。

实测（页面内读高德覆盖物选项）：

| 指标 | 数值 |
|---|---|
| 省级行政区面数量 | 68（21 市州多环合并后） |
| 样本 `fillColor / fillOpacity` | `#061a34 / 0.22` |
| 触发 `mouseover` 后 | `0.42` |
| 触发 `mouseout` 后 | 回到 `0.22` |

## 2. 点击辖区 = 原地缩放，不再重建地图

改造前：`GeoMap` 的建图 effect 依赖 `[mode, features]`，点一个市就换 `features` → 销毁 `AMap.Map` 再 `new`，肉眼表现为「整页闪一下再切换」（底图瓦片重载、缩放级别重置为 7）。

改造后拆成两个 effect：

| effect | 依赖 | 职责 |
|---|---|---|
| 建图（3） | `[mode]` | 只创建一次 `AMap.Map`、卫星层、点击/缩放监听、ResizeObserver |
| 行政区面（3b） | `[mode, features]` | 摘掉上一级面 → 铺新面 → `map.setBounds(bounds, false, [24,24,24,24])` 平滑缩放到新辖区（`immediately=false` 走动画，另在 320ms 后补一次以避开首帧尺寸未就绪） |

因此下钻/返回时：地图实例、底图瓦片、主题样式都保持不变，**只有面图层和缩放级别变化**。

实测（同一页面内，先给实例打标记再点击）：

| 阶段 | 实例标记 | 面数量 | zoom | 面包屑 |
|---|---|---|---|---|
| 省级（初始） | `online-1795053839261` | 68 | 6.88 | 四川省 |
| 点击首个行政区面（=成都市） | `online-1795053839261`（**未变**） | 26 | 9.49 | 四川省 / 成都市 |
| 点面包屑「四川省」返回 | `online-1795053839261`（**未变**） | 68 | 5.63 | 四川省 |

- 实例标记不变即证明地图没有销毁重建；
- 面数量 68 → 26 → 68 说明图层在原地替换；
- zoom 6.88 → 9.49 → 5.63 是缩放动画的结果。

| 文件 | 改动 |

- 390×844：`docW=390`、地图 366×320、底部收起胶囊 60×30 @(165,378)。

## 5. 已知取舍

1. 首次进入与「返回省级」的缩放级别略有差异（6.88 / 5.63），因为 `setBounds` 的可用区域取决于容器最终尺寸；视觉上都是「四川省完整入画」，未做硬编码级别。
2. 掩膜只覆盖当前层级的多边形：省级视角下邻省不被压暗（这是 v9 的既定口径），若希望邻省也压暗，需要恢复全域暗化面，与 v9 要求冲突，需明确取舍。
