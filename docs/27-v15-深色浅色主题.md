# v15 · 深色 / 浅色双主题

> 目标：同一套 CoinPulse 色彩体系，提供「深色（默认）」与「浅色」两种模式，可随时切换并记住选择。
> 不改变任何业务口径、不新增页面、不改动布局尺寸（只换颜色与阴影）。

## 1. 切换入口与记忆

| 项 | 说明 |
|---|---|
| 入口 | 顶栏右侧、`问题监测` 左侧的方形图标按钮（深色时显示太阳，浅色时显示月亮） |
| 快捷键 | 无（避免与浏览器/输入法冲突） |
| 记忆 | `localStorage['kq_theme']`，值 `dark` / `light`，默认 `dark` |
| 生效范围 | 全站（登录页、驾驶舱、业务中枢、台账、数据仓、移动端、系统、作战图） |
| 实现 | `web/src/theme.jsx`：`ThemeProvider` + `useTheme()`；写入 `document.documentElement.dataset.theme` |

## 3. 落地位置（改了什么）

| 文件 | 改动 |
|---|---|
| `web/src/theme.jsx` | 新增：主题上下文、`localStorage` 持久化、`html[data-theme]` 写入 |
| `web/src/main.jsx` | `ThemeProvider` 包裹；`Root` 内按 `mode` 生成 antd 主题，懒加载 demo 数据层不变 |
| `web/src/ui/antdTheme.js` | 新增 `antdThemeFor(mode)`：`darkAlgorithm` ↔ `defaultAlgorithm`，Table/Tabs/Segmented/Modal/Drawer/Tag/Descriptions/Card/Pagination/Steps/Upload/Empty 逐组件换色 |
| `web/src/styles/theme.css` | 新增：`html[data-theme="light"]` 的令牌覆盖 + 组件级覆盖（顶栏、导航轨、面板、表格、表单、按钮、芯片、驾驶舱 chrome、地图浮层、登录页、弹层） |
| `web/src/styles/pages.css`、`components.css` | 53 处 CoinPulse 字面色改为 CSS 变量（`#18181b → var(--panel)` 等），主题切换才可能生效 |
| `web/src/layout/Shell.jsx` | 顶栏新增主题切换按钮（`Sun01Icon` / `Moon02Icon`） |
| `web/src/components/GeoMap.jsx` | 新增 `themeMode`：深色用 `amap://styles/dark` + 卫星层 + 深色掩膜；浅色用 `amap://styles/normal`、不铺卫星层、掩膜改浅灰（`#f4f4f5 / #e4e4e7 / #dbeafe`）；气泡底色与文字随主题；主题变化时重建地图与图层 |
| `web/src/components/Chart.jsx` | 新增 `adaptForTheme()`：浅色下把画布文字/轴线色映射为深色可读值（`#fafafa→#18181b` 等），并在 `mode` 变化时重新 `setOption` |
| `web/src/pages/Cockpit.jsx` | 地图专题牌改 `.map-plate`（主题接管底色/边框/阴影）；区域下拉、工具/图层按钮、测距提示条改主题变量 |

## 5. 已知边界

1. **地图瓦片**：浅色用高德 `normal` 样式（非卫星），因此浅色下看不到卫星纹理；深色仍是 dark + 叠加卫星晕渲（opacity 0.45）。
2. **图表色板**：数据系列的 8 色（蓝/青柠/琥珀/绿/红…）两套主题共用；只有画布上的文字与轴线随主题映射，因为 canvas 不解析 CSS 变量。
3. **打印**：未做专门的打印样式，浅色模式更接近纸质观感。
4. **第三方弹窗**：高德自带的 logo/版权条两套主题均保留（透明度 0.42）。
