## 4. 与截图的已知偏差（如实标注）

| # | 偏差 | 原因 | 处理 |
| --- | --- | --- | --- |
| D-01 | 地图底图为「高德卫星影像 + 全域暗化层 + 行政区暗色蒙版」合成，与截图的实景卫星仍有色差与清晰度差异 | 截图取自政务专网的高分辨率影像底图；本项目用高德公开瓦片（`AMap.TileLayer.Satellite`，`opacity:0.45`），其上叠一张覆盖全省域的暗化面（`#04101f` / 0.52，`zIndex:2`）压暗邻省，再用行政区面 `#061a34` / 0.34（`zIndex:5`）统一蓝色调 | 三层参数集中在 `web/src/components/GeoMap.jsx`：卫星层 opacity、`veil` 的 fillColor/fillOpacity、`MASK_FILL` 常量；接入专网影像只需换 `TileLayer` 的 URL 模板 |
| D-02 | 省级视角显示 21 个市州气泡，截图显示 5 个区县气泡 | 截图是湖州市视角；演示口径为四川全省 | 点击市州下钻后即显示该市下辖区县气泡（与截图同构） |
| D-03 | 矿山图斑为按面积折算的示意多边形 | 演示库无真实矿区红线矢量 | 位置取库内经纬度，形状为八边形示意；接真实矿权范围后可直接替换 |
| D-04 | 导航条为 40px 次级条（截图顶部导航与横幅同区） | 需求文档要求保留一级场景切换导航 | 视觉上压暗、缩小，不与横幅抢焦点 |
| D-05 | 绿色矿山列表「入库时间」列改为「有效期始」 | 数据表无 `green_in_at` 字段 | 见 `docs/02` C-03；补字段后改回 |
| D-06 | ~~高德底图可见一条红色省界线~~ **已修复** | 根因：高德 JS API 把「国界线」并入 `features` 的 `road` 特征组渲染，`amap://styles/dark` 样式下西南段国界线被画成红色虚线（位置正对川西察隅/米什米一带），演示时会被误读为告警 | 构造地图时改为 `features: ['bg','point']`（去掉 `road`，保留陆地/水域与地名），红线消失；代价是底图不再绘制省界与道路，改由我们的行政区划描边承担边界表达。证据 `docs/shots/style/redfix-before.png` / `redfix-after.png` |
| D-07 | 390px 顶栏隐藏日期/胶囊、标题改短 | 窄屏无法容纳截图版式 | 响应式取舍，功能入口在「更多」菜单与页面内保留 |

cd web && npm run build

# 2) 起服务（Express 托管 dist）

# 3) 登录 admin / admin123 → 平台分布 → 首页驾驶舱 → 作战图 → 矿业权 › 净矿出让
