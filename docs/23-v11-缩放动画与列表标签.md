# v11 · 下钻缩放动画与底部列表标签

本轮只处理两条反馈，改动集中在 `web/src/components/GeoMap.jsx`、`web/src/pages/Cockpit.jsx`、`web/src/styles/pages.css` 三个文件，接口、数据与业务规则未动。

---

## 1. 缩放慢一些、动画更顺

### 问题

v10 把下钻改成了「原地重绘行政区面 + `map.setBounds(bounds, false, avoid)`」，实测仍然是一下子到位：`setBounds` 在 2.0 里没有时长参数，`setZoomAndCenter(zoom, center, false, 1200)` 的 `duration` 也只有约 300ms 可见效果（采样：6.88 → 7.46（151ms）→ 8.88（308ms）后不再变化）。

### 做法

新增 `tweenView(map, to, durationMs, rafRef)`（`GeoMap.jsx` 顶部），不再依赖高德自带动画：

| 项 | 取值 |
|---|---|
| 时长 | `ZOOM_MS = 1200`（ms） |
| 缓动 | `easeInOutQuad`：`t<0.5 ? 2t² : 1-(-2t+2)²/2` |
| 插值对象 | `zoom` 与 `center`（经纬度线性插值） |
| 落位方式 | 每帧 `map.setZoomAndCenter(z, c, true)`，`immediately=true` 避免与高德自己的动画叠加 |
| 目标级别 | 由辖区外接框按 Web 墨卡托换算：`min(log2(w/xUnit), log2(h/yUnit))`，再夹到 `[4,15]` |
| 兜底 | `setTimeout(duration+400)` 强制落位：后台标签页 rAF 被节流时不会卡在中间视野 |

`flyTo()` 里原来的 `setBounds` 调用改为 `tweenView(m, { zoom, center }, ZOOM_MS, tweenRef)`；3b effect 的清理函数同时 `cancelAnimationFrame` 和 `clearTimeout`，避免连续下钻时两个动画互相拉扯。

### 实测

本地（真实 API，1920×1080，点击成都市辖区），每 40ms 采样一次 zoom：

| 时间 ms | 50 | 202 | 401 | 613 | 800 | 921 | 1040 | 1121 | 1200 |
|---|---|---|---|---|---|---|---|---|---|
| zoom | 6.88 | 6.97 | 7.35 | 8.05 | 8.78 | 9.12 | 9.35 | 9.44 | **9.49** |

- 整段 1.2s，`68 → 26` 个行政区面，面包屑变为「四川省 / 成都市」。
- 曲线是 S 形：前 200ms 只涨 0.09，中段（600–900ms）涨得最快，末段收敛，符合 `easeInOutQuad`。

线上（IGA，demo 模式）：同样点击后 `zoom 6.88 → 9.49`、`68 → 26` 面、面包屑正确。线上采样时页面处于后台节流状态，rAF 几乎不回调，由兜底定时器直接落位——这是浏览器对不可见标签页的通用限制，真实用户在前台使用时按 60fps 逐帧动画。

## 已知取舍

1. 动画依赖 `requestAnimationFrame`。浏览器把标签页判定为不可见时 rAF 会被压到 1 次/秒，此时由兜底定时器直接落位，观感是「瞬间到位」而不是「卡在中间」。
2. 目标级别由容器尺寸与外接框算出，不同窗口宽度下的首屏级别会略有差异（1920 下省级 6.88、市级 9.49）。
3. 缓动时长固定 1.2s，未提供「快速模式」；若演示需要更快，可把 `ZOOM_MS` 调成 700–800。
