## 3. 页面模板（`styles/pages.css`）

所有业务页统一为三段，顺序固定：

```
.page-head       .page-title(h1)  .page-desc  .page-actions
.kpi-row         .kpi-card × 3~4     （.kpi-label / .kpi-value / .kpi-unit / .kpi-delta）
.content         .toolbar + 主体（.card 或 .content-grid）
```

| 类 | 用途 |
|---|---|
| `.page-title` `.page-desc` `.page-actions` | 页头三件套；标题 28px，描述 13px `--text-3`，操作右对齐 |
| `.kpi-row` `.kpi-card` | 指标带；卡片等高、`--panel` 底，数值 28px 等宽数字 |
| `.toolbar` `.toolbar-filters` `.toolbar-search` `.toolbar-actions` | 工具栏；左侧筛选，中间关键词，右侧操作 |
| `.card` `.card-head` `.card-title` `.card-body` | 卡片唯一形态 |
| `.content-grid` `.content-grid--2` `.content-grid--3` | 主内容分栏（12 栅格，窄屏自动单列） |

## 7. 交互状态约定

| 状态 | 表现 |
|---|---|
| 加载 | 首屏用 `.skeleton` 3 行；局部刷新用按钮 `is-loading`（转圈 + 禁用） |
| 空 | `.empty`：图标 + 一句「暂无数据」+ 次要操作（如「重置筛选」） |
| 错误 | 卡片内 `.empty` 变体 + 「重试」按钮，不弹全局 alert |
| 权限 | 无权限时隐藏主操作按钮，保留只读视图 |
| 危险操作 | 一律 `.btn-danger` + 二次确认抽屉（不是浏览器 confirm） |

## 9. 校验

`scripts/check-classes.mjs`：扫描 `web/src/**/*.jsx` 的 `className` 字面量，
凡不在 tokens/base/components/pages 四层 CSS 中出现的类名 → 报 `UNKNOWN_CLASS`，
退出码非 0。第三方类（`amap-*`、`spotlight-card`、`threads-container` 等）走白名单。

> 注：§4/§6 中的斜杠简写（`.tag--green/red/yellow/orange/blue/grey`、`.badge--ok/warn/off`、
> `.flag--done/doing/late/none`）实现时必须**逐个类名存在**于 CSS，否则页面用到的那一个会被判 `UNKNOWN_CLASS`。

## 10. 追加组件（lead 已批准，U-01…U-10 全部生效）

`ux-design` 于 2026-11-18 登记，lead 全部批准并冻结如下类名与规格；`ds-build` 必须实现，页面组可直接使用。

| 编号 | 类名（冻结） | 规格 |
|---|---|---|
| U-01 | `.breadcrumb` > `a` + `span.sep` | 高 20，字号 12；非末项 `--text-3` hover `--cyan`，末项 `--text-2` 不可点；分隔符 `/` |
| U-02 | `.desc-list` > `.desc-row` > `.desc-key` + `.desc-value` | 两列栅格 `max-content 1fr`，行距 8，行下边框 1px `--line`（末行无）；`.desc-key` 12px `--text-3`，`.desc-value` 13px `--text-1` 允许换行 |
| U-03 | `.content-col` | 纵向 flex，`gap: var(--sp-4)`，`min-width:0`，可嵌套进 `.content-grid` |
| U-04 | `.qr` > `img.qr-img` + `.qr-cap` | 图 128×128（白底 4px 内边距），`.qr-cap` 11px `--text-3` 居中，间距 6 |
| U-05 | `.drawer--lg`（720px）/ `.drawer--full`（100vw） | 覆盖内联 width；`.drawer--full` 无圆角、无阴影 |
| U-06 | `.upload` > `.upload-box` + `.upload-hint` | 虚线 1px `--line-strong` 圆角 12，高 96，居中图标+文案；hover 描边 `--cyan` |
| U-07 | `.empty.is-error` + `.empty-action` | 错误态标题 `--red`，`.empty-action` 为 `.btn.btn-ghost.btn-sm` 容器，间距 12 |
| U-08 | `.steps` > `.step`（`.is-done` / `.is-on`） | 横向 6 列自适应；序号圆点 22，连接线 1px `--line`；done 绿、on 青、其余灰 |
| U-09 | `.table-wrap--fill` | `flex:1 1 auto; min-height:0; overflow:auto`，配合 `.card-body` 撑满剩余高度，分页贴底 |
| U-10 | `.is-loading` | 元素内联转圈（::after），`pointer-events:none`、`opacity:.72` |

`check-classes.mjs` 白名单需放行 `is-error` / `is-done` / `is-on` / `is-loading` / `is-open` / `is-warn` / `is-danger` 等状态类（这些与基础类成对出现，不算未知类）。
